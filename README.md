# Task Manager App 
A modern Task Management Web application built with Laravel and containerized using Docker for seamless development and deployment. 

**Backend Framework:** PHP 8.3/Laravel 
**Frontend :** HTML,CSS3,javaScript, livewire
**Database:** MySQL 
**Containerization:** Docker & Docker Compose
**Version Control:** Git & GitHub

## Getting Started with Docker

Follow these step-by-step instructions to build and run the application locally using Docker.

### Prerequisites

Ensure you have the following installed on your machine:
* [Docker Desktop](https://www.docker.com/products/docker-desktop/)
* [Git](https://git-scm.com/)
